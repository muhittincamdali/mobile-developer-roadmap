Una hoja de ruta de aprendizaje para desarrolladores móviles: primero los fundamentos comunes, después iOS, Android, Flutter y React Native, y por último la práctica de ingeniería que mantiene una app funcionando después de su primera versión. Tiene 124 temas. Cada uno indica qué aprender, qué temas conviene aprender antes, un proyecto pequeño para practicar y dónde aprenderlo: solo fuentes primarias, como la documentación de Apple, Android, Flutter, Dart, React Native y Expo, las propuestas de Swift Evolution, los RFC y OWASP. El contenido está al día a octubre de 2026: Swift 6.4 y Xcode 27, el SDK de iOS 27 con su ciclo de vida de scenes obligatorio y Liquid Glass, Android 16, Flutter 3.47 con Dart 3.13 y React Native 0.88 con Expo SDK 58.

Puedes leer la hoja de ruta aquí, en GitHub, planificar tu propio camino por ella en la terminal con el comando `roadmap` o seguirla en la app RoadmapExplorer para iPhone, iPad y Mac.

## Lo más destacado

- **Un camino, no una lista** — cada tema indica los temas que necesita, de modo que `roadmap path` convierte un objetivo en la lista ordenada de temas que hay que aprender, saltándose los que ya conoces.
- **Solo fuentes primarias** — 301 enlaces a documentación oficial y estándares. Un linter rechaza blogs, cursos y repositorios personales, y la comprobación de enlaces solicita cada URL todas las semanas.
- **Plataformas actuales** — el ciclo de vida de UIScene que deben adoptar las apps compiladas con el SDK de iOS 27, Liquid Glass (la exclusión por compatibilidad se ignora en las compilaciones para iOS 27), la seguridad frente a data races de Swift 6, las reglas de pantalla grande de Android 16, la migración de Flutter a UIScene y la New Architecture de React Native, que es la única desde la 0.82.
- **Práctica en cada tema** — un proyecto pequeño por tema, la mayoría construidos sobre la misma app de recetas, de modo que la práctica se va acumulando.
- **Un solo formato, comprobado** — los temas son Markdown simple con una estructura fija, así que los mismos archivos alimentan GitHub, la línea de comandos, la app y la biblioteca [RoadmapKit](#usa-la-biblioteca); las pruebas fallan cuando falta una dependencia, aparece un ciclo o un número de la documentación deja de coincidir.

## Inicio rápido

**1. Obtén la hoja de ruta**

```sh
git clone https://github.com/muhittincamdali/mobile-developer-roadmap.git
cd mobile-developer-roadmap
```

Necesitas Swift 6.2 o posterior: Xcode 26 o posterior en un Mac, o un [Swift toolchain](https://www.swift.org/install/) en Linux. Para leer los archivos Markdown no necesitas nada.

**2. Planifica un camino hacia un objetivo**

Indica el tema al que quieres llegar y los temas que ya conoces:

```sh
swift run roadmap path ios/swift-6-mode --known foundations/programming,ios/swift
```

La primera ejecución compila la herramienta. Después muestra los temas en el orden en que conviene aprenderlos:

```console
$ swift run roadmap path ios/swift-6-mode --known foundations/programming,ios/swift
Path to ios/swift-6-mode: 7 topics

1. foundations/http · beginner · HTTP and web APIs
2. foundations/json · beginner · JSON and data formats
3. foundations/async · beginner · Asynchronous code and the main thread
4. ios/optionals-and-errors · beginner · Optionals and error handling
5. ios/networking · beginner · Networking with URLSession and Codable
6. ios/concurrency · intermediate · Swift concurrency
7. ios/swift-6-mode · intermediate · The Swift 6 language mode  ← goal

Skipped, already known: foundations/programming, ios/swift
```

**3. Abre el primer tema**

```sh
swift run roadmap show foundations/http
```

Esto muestra qué aprender, el proyecto de práctica, los temas a los que lleva y sus enlaces. Guarda los temas que termines en un archivo de texto, un ID por línea, y pregunta qué puedes empezar a continuación:

```sh
printf 'foundations/programming\nios/swift\nfoundations/http\n' > my-progress.txt
swift run roadmap next --known-file my-progress.txt --track ios
```

## Commands

| Comando | Qué hace |
| --- | --- |
| `roadmap tracks` | Temas por ruta y nivel |
| `roadmap list --track flutter --stage beginner` | Lista los ID, los niveles y los títulos; también admite `--search` |
| `roadmap show react-native/new-architecture` | Muestra un tema con su práctica, sus requisitos, los temas que dependen de él y sus enlaces |
| `roadmap path <ID>... --known <IDs>` | Los temas ordenados para llegar hasta 32 objetivos; también admite `--known-file` |
| `roadmap next --known-file my-progress.txt` | Temas cuyos requisitos ya conoces; también admite `--track` |
| `roadmap graph --track android` | Una ruta como diagrama de flujo de Mermaid, que GitHub renderiza |
| `roadmap lint` | Comprueba los archivos de la hoja de ruta; estado de salida 1 si hay algún problema |

Ejecuta `swift run roadmap --help` para ver la lista completa. Una entrada no válida, como una ruta desconocida o una línea del archivo de progreso que no es un ID de tema, se notifica con el estado de salida 2 en lugar de provocar un fallo; un ID con formato correcto que no está en la hoja de ruta, con el estado de salida 1.

## Ejemplo: un tema

Cada tema es una sección de Markdown con un ID, un nivel, sus requisitos, un resumen, un proyecto de práctica y sus fuentes. Este es `ios/app-life-cycle` en [roadmap/ios.md](roadmap/ios.md):

```markdown
## ios/app-life-cycle: The app and scene life cycle

**Stage:** beginner · **Needs:** ios/swiftui

- An app has one process and one or more scenes (windows); each scene becomes active, inactive
  and enters the background on its own.
- In SwiftUI, `App` and `WindowGroup` are scene-based, and `scenePhase` reports the changes.
- UIKit apps move from `UIApplicationDelegate` window code to `UISceneDelegate`. Apple's TN3187
  says that from the release after iOS 26, an app built with the latest SDK that does not
  adopt the scene life cycle will not launch: with Xcode 27 and the iOS 27 SDK this is required.

**Practice:** Save a draft when the scene goes to the background and restore it on the next launch.

**Learn from:**

- [TN3187: Migrating to the UIKit scene-based life cycle](https://developer.apple.com/documentation/technotes/tn3187-migrating-to-the-uikit-scene-based-life-cycle)
- [Managing your app's life cycle](https://developer.apple.com/documentation/uikit/managing-your-app-s-life-cycle)
- [ScenePhase](https://developer.apple.com/documentation/swiftui/scenephase)
```

## Usa la biblioteca

La biblioteca `RoadmapKit` lee, comprueba y planifica los archivos de la hoja de ruta desde tu propio código Swift. Añádela con Swift Package Manager:

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/mobile-developer-roadmap.git", from: "2.0.0")
],
targets: [
    .target(name: "MyLearningTool", dependencies: [
        .product(name: "RoadmapKit", package: "mobile-developer-roadmap")
    ])
]
```

```swift
import Foundation
import RoadmapKit

let roadmap = try Roadmap.load(from: URL(fileURLWithPath: "roadmap"))
let plan = try roadmap.plan(to: ["flutter/architecture"], knowing: ["foundations/programming"])
for (number, topic) in plan.steps.enumerated() {
    print(number + 1, topic.id, topic.title)
}
```

La lectura tiene límites (1 MiB por archivo, 500 temas por archivo, 32 requisitos y 16 enlaces por tema, 100 problemas notificados por archivo), y cada problema de formato se devuelve como un `Diagnostic` con archivo y línea en lugar de una excepción.
