モバイル開発者のための学習ロードマップです。共通の基礎から始まり、iOS、Android、Flutter、React Native と進み、最後に、最初のリリース後もアプリを動かし続けるためのエンジニアリングの実践を扱います。トピックは全部で 124 あります。各トピックには、何を学ぶか、先に学ぶべきトピック、練習用の小さなプロジェクト、学習に使う情報源が示されています。情報源は一次情報に限っており、Apple、Android、Flutter、Dart、React Native、Expo のドキュメント、Swift Evolution の提案、RFC、OWASP などです。内容は 2026 年 10 月時点の最新です。Swift 6.4 と Xcode 27、シーンのライフサイクルが必須で Liquid Glass を備えた iOS 27 SDK、Android 16、Dart 3.13 を伴う Flutter 3.47、Expo SDK 58 を伴う React Native 0.88 を対象としています。

ロードマップは GitHub 上でそのまま読めます。ターミナルで `roadmap` コマンドを使って自分専用の学習パスを組み立てることも、iPhone、iPad、Mac 向けの RoadmapExplorer アプリで追うこともできます。

## 主な特長

- **リストではなく、道筋** — どのトピックも必要とするトピックを明示しているため、`roadmap path` は目標を、すでに知っているものを除いた学習順のトピック一覧に変えてくれます。
- **一次情報のみ** — 公式ドキュメントと標準規格へのリンクが 301 件あります。ブログ、講座、個人のリポジトリは linter が拒否し、リンクチェックは毎週すべての URL にアクセスします。
- **最新のプラットフォーム** — iOS 27 SDK でビルドするアプリが採用しなければならない UIScene ライフサイクル、Liquid Glass（互換性のためのオプトアウトは iOS 27 のビルドでは無視されます）、Swift 6 のデータ競合安全性、Android 16 の大画面向けルール、Flutter の UIScene への移行、そして 0.82 以降は唯一の選択肢となった React Native の New Architecture。
- **すべてのトピックに練習つき** — トピックごとに小さなプロジェクトが 1 つあり、その多くは同じレシピアプリを発展させる形なので、練習が積み上がります。
- **ひとつの形式を、検証つきで** — トピックは構造が決まったプレーンな Markdown です。同じファイルが GitHub、コマンドライン、アプリ、[RoadmapKit](#ライブラリを使う) ライブラリを支えており、必要なトピックが欠けたとき、循環が生じたとき、ドキュメント内の数が実態とずれたときにはテストが失敗します。

## クイックスタート

**1. ロードマップを入手する**

```sh
git clone https://github.com/muhittincamdali/mobile-developer-roadmap.git
cd mobile-developer-roadmap
```

Swift 6.2 以降が必要です。Mac では Xcode 26 以降、Linux では [Swift toolchain](https://www.swift.org/install/) を使います。Markdown ファイルを読むだけなら、何も必要ありません。

**2. 目標までのパスを組み立てる**

到達したいトピックと、すでに知っているトピックを指定します。

```sh
swift run roadmap path ios/swift-6-mode --known foundations/programming,ios/swift
```

初回の実行ではツールがビルドされます。そのあと、学ぶ順にトピックが表示されます。

```console
$ swift run roadmap path ios/swift-6-mode --known foundations/programming,ios/swift
Path to ios/swift-6-mode: 7 topics

1. foundations/http · beginner · HTTP and web APIs
2. foundations/json · beginner · JSON and data formats
3. foundations/async · beginner · Asynchronous code and the main thread
4. ios/optionals-and-errors · beginner · Optionals and error handling
5. ios/networking · beginner · Networking with URLSession and Codable
6. ios/concurrency · intermediate · Swift concurrency
7. ios/swift-6-mode · intermediate · The Swift 6 language mode  ← goal

Skipped, already known: foundations/programming, ios/swift
```

**3. 最初のトピックを開く**

```sh
swift run roadmap show foundations/http
```

学ぶ内容、練習プロジェクト、次に進むトピック、リンクが表示されます。終えたトピックは、1 行に 1 つの ID でテキストファイルに記録しておき、次に始められるものを問い合わせます。

```sh
printf 'foundations/programming\nios/swift\nfoundations/http\n' > my-progress.txt
swift run roadmap next --known-file my-progress.txt --track ios
```

## Commands

| コマンド | 内容 |
| --- | --- |
| `roadmap tracks` | トラックごと、段階ごとのトピック数 |
| `roadmap list --track flutter --stage beginner` | ID、段階、タイトルを一覧表示します。`--search` も使えます |
| `roadmap show react-native/new-architecture` | 1 つのトピックを、練習、必要なトピック、依存先、リンクとともに表示します |
| `roadmap path <ID>... --known <IDs>` | 最大 32 個の目標に到達するための、順序つきのトピック。`--known-file` も使えます |
| `roadmap next --known-file my-progress.txt` | 必要なトピックをすべて知っているトピック。`--track` も使えます |
| `roadmap graph --track android` | トラックを Mermaid のフローチャートとして出力します。GitHub 上で描画されます |
| `roadmap lint` | ロードマップのファイルを検査します。問題があれば終了ステータスは 1 です |

全一覧は `swift run roadmap --help` で確認できます。不明なトラックや、進捗ファイル内のトピック ID ではない行といった不正な入力は、クラッシュせずに終了ステータス 2 で報告されます。形式は正しいもののロードマップに存在しない ID は、終了ステータス 1 で報告されます。

## 例：1 つのトピック

各トピックは、ID、段階、必要なトピック、要約、練習プロジェクト、情報源を持つ Markdown のセクションです。次は [roadmap/ios.md](roadmap/ios.md) にある `ios/app-life-cycle` です。

```markdown
## ios/app-life-cycle: The app and scene life cycle

**Stage:** beginner · **Needs:** ios/swiftui

- An app has one process and one or more scenes (windows); each scene becomes active, inactive
  and enters the background on its own.
- In SwiftUI, `App` and `WindowGroup` are scene-based, and `scenePhase` reports the changes.
- UIKit apps move from `UIApplicationDelegate` window code to `UISceneDelegate`. Apple's TN3187
  says that from the release after iOS 26, an app built with the latest SDK that does not
  adopt the scene life cycle will not launch: with Xcode 27 and the iOS 27 SDK this is required.

**Practice:** Save a draft when the scene goes to the background and restore it on the next launch.

**Learn from:**

- [TN3187: Migrating to the UIKit scene-based life cycle](https://developer.apple.com/documentation/technotes/tn3187-migrating-to-the-uikit-scene-based-life-cycle)
- [Managing your app's life cycle](https://developer.apple.com/documentation/uikit/managing-your-app-s-life-cycle)
- [ScenePhase](https://developer.apple.com/documentation/swiftui/scenephase)
```

## ライブラリを使う

`RoadmapKit` ライブラリを使うと、自分の Swift コードからロードマップのファイルを読み込み、検査し、パスを計画できます。Swift Package Manager で追加します。

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/mobile-developer-roadmap.git", from: "2.0.0")
],
targets: [
    .target(name: "MyLearningTool", dependencies: [
        .product(name: "RoadmapKit", package: "mobile-developer-roadmap")
    ])
]
```

```swift
import Foundation
import RoadmapKit

let roadmap = try Roadmap.load(from: URL(fileURLWithPath: "roadmap"))
let plan = try roadmap.plan(to: ["flutter/architecture"], knowing: ["foundations/programming"])
for (number, topic) in plan.steps.enumerated() {
    print(number + 1, topic.id, topic.title)
}
```

読み込みには上限があります（1 ファイルあたり 1 MiB と 500 トピック、1 トピックあたり必要なトピック 32 件とリンク 16 件、1 ファイルあたり報告される問題 100 件）。形式上の問題はどれも、例外ではなく、ファイルと行を持つ `Diagnostic` として返されます。
