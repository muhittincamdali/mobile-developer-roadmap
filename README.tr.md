Mobil geliştiriciler için bir öğrenme yol haritası: ortak temeller, ardından iOS, Android, Flutter ve React Native, en sonda da bir uygulamayı ilk sürümden sonra da çalışır tutan mühendislik pratiği. Yol haritasında 124 konu var. Her konu neyi öğreneceğinizi, önce hangi konuları öğrenmeniz gerektiğini, pratik yapmak için küçük bir projeyi ve nereden öğreneceğinizi söyler. Kaynaklar yalnızca birincil kaynaklardır: Apple, Android, Flutter, Dart, React Native ve Expo dokümantasyonu, Swift Evolution önerileri, RFC'ler ve OWASP. İçerik Ekim 2026 itibarıyla günceldir: Swift 6.4 ve Xcode 27, zorunlu scene yaşam döngüsü ve Liquid Glass ile iOS 27 SDK, Android 16, Dart 3.13 ile Flutter 3.47, Expo SDK 58 ile React Native 0.88.

Yol haritasını burada GitHub'da okuyabilir, `roadmap` komutuyla terminalde kendi yolunuzu planlayabilir ya da iPhone, iPad ve Mac için RoadmapExplorer uygulamasından takip edebilirsiniz.

## Öne çıkanlar

- **Liste değil, yol** — her konu ihtiyaç duyduğu konuları belirtir; böylece `roadmap path` bir hedefi, zaten bildiklerinizi atlayarak öğrenilecek konuların sıralı listesine dönüştürür.
- **Yalnızca birincil kaynaklar** — resmî dokümantasyon ve standartlara 301 bağlantı. Bir linter blogları, kursları ve kişisel depoları reddeder; bağlantı denetimi her hafta tüm adresleri ister.
- **Güncel platformlar** — iOS 27 SDK ile derlenen uygulamaların benimsemesi gereken UIScene yaşam döngüsü, Liquid Glass (uyumluluk için vazgeçme seçeneği iOS 27 derlemelerinde yok sayılır), Swift 6 veri yarışı güvenliği, Android 16 büyük ekran kuralları, Flutter'ın UIScene geçişi ve 0.82'den beri tek seçenek olan React Native New Architecture.
- **Her konu için pratik** — konu başına bir küçük proje; çoğu aynı tarif uygulaması üzerine kurulur, böylece pratik birikir.
- **Tek biçim, denetimli** — konular sabit yapıda düz Markdown'dır; aynı dosyalar GitHub'ı, komut satırını, uygulamayı ve [RoadmapKit](#kütüphaneyi-kullanın) kütüphanesini besler. Bir ihtiyaç eksikse, döngü oluşursa ya da dokümandaki bir sayı kayarsa testler başarısız olur.

## Hızlı başlangıç

**1. Yol haritasını edinin**

```sh
git clone https://github.com/muhittincamdali/mobile-developer-roadmap.git
cd mobile-developer-roadmap
```

Swift 6.2 veya üstü gerekir: Mac'te Xcode 26 veya üstü, Linux'ta ise bir [Swift toolchain](https://www.swift.org/install/). Markdown dosyalarını okumak için hiçbir şeye gerek yoktur.

**2. Bir hedefe giden yolu planlayın**

Ulaşmak istediğiniz konuyu ve zaten bildiğiniz konuları belirtin:

```sh
swift run roadmap path ios/swift-6-mode --known foundations/programming,ios/swift
```

İlk çalıştırma aracı derler. Ardından konuları öğrenme sırasına göre yazdırır:

```console
$ swift run roadmap path ios/swift-6-mode --known foundations/programming,ios/swift
Path to ios/swift-6-mode: 7 topics

1. foundations/http · beginner · HTTP and web APIs
2. foundations/json · beginner · JSON and data formats
3. foundations/async · beginner · Asynchronous code and the main thread
4. ios/optionals-and-errors · beginner · Optionals and error handling
5. ios/networking · beginner · Networking with URLSession and Codable
6. ios/concurrency · intermediate · Swift concurrency
7. ios/swift-6-mode · intermediate · The Swift 6 language mode  ← goal

Skipped, already known: foundations/programming, ios/swift
```

**3. İlk konuyu açın**

```sh
swift run roadmap show foundations/http
```

Bu komut neyi öğreneceğinizi, pratik projesini, hangi konulara götürdüğünü ve bağlantılarını yazdırır. Bitirdiğiniz konuları her satırda bir ID olacak şekilde bir metin dosyasında tutun ve sırada neye başlayabileceğinizi sorun:

```sh
printf 'foundations/programming\nios/swift\nfoundations/http\n' > my-progress.txt
swift run roadmap next --known-file my-progress.txt --track ios
```

## Commands

| Komut | Ne yapar |
| --- | --- |
| `roadmap tracks` | Alan ve seviye başına konu sayısı |
| `roadmap list --track flutter --stage beginner` | ID'leri, seviyeleri ve başlıkları listeler; `--search` de kullanılabilir |
| `roadmap show react-native/new-architecture` | Bir konuyu pratiği, ihtiyaçları, kendisine bağlı konuları ve bağlantılarıyla gösterir |
| `roadmap path <ID>... --known <IDs>` | En fazla 32 hedefe ulaşmak için sıralı konular; `--known-file` de kullanılabilir |
| `roadmap next --known-file my-progress.txt` | İhtiyaçlarını zaten bildiğiniz konular; `--track` de kullanılabilir |
| `roadmap graph --track android` | Bir alanı GitHub'ın görüntülediği Mermaid akış şeması olarak verir |
| `roadmap lint` | Yol haritası dosyalarını denetler; herhangi bir sorunda çıkış durumu 1 olur |

Tam liste için `swift run roadmap --help` komutunu çalıştırın. Bilinmeyen bir alan ya da ilerleme dosyasında konu ID'si olmayan bir satır gibi geçersiz girdi çökmek yerine 2 çıkış durumuyla bildirilir; biçimi doğru olup yol haritasında bulunmayan bir ID ise 1 çıkış durumuyla.

## Örnek: bir konu

Her konu; bir ID, bir seviye, ihtiyaçlar, bir özet, bir pratik projesi ve kaynaklardan oluşan bir Markdown bölümüdür. Aşağıdaki, [roadmap/ios.md](roadmap/ios.md) içindeki `ios/app-life-cycle` konusudur:

```markdown
## ios/app-life-cycle: The app and scene life cycle

**Stage:** beginner · **Needs:** ios/swiftui

- An app has one process and one or more scenes (windows); each scene becomes active, inactive
  and enters the background on its own.
- In SwiftUI, `App` and `WindowGroup` are scene-based, and `scenePhase` reports the changes.
- UIKit apps move from `UIApplicationDelegate` window code to `UISceneDelegate`. Apple's TN3187
  says that from the release after iOS 26, an app built with the latest SDK that does not
  adopt the scene life cycle will not launch: with Xcode 27 and the iOS 27 SDK this is required.

**Practice:** Save a draft when the scene goes to the background and restore it on the next launch.

**Learn from:**

- [TN3187: Migrating to the UIKit scene-based life cycle](https://developer.apple.com/documentation/technotes/tn3187-migrating-to-the-uikit-scene-based-life-cycle)
- [Managing your app's life cycle](https://developer.apple.com/documentation/uikit/managing-your-app-s-life-cycle)
- [ScenePhase](https://developer.apple.com/documentation/swiftui/scenephase)
```

## Kütüphaneyi kullanın

`RoadmapKit` kütüphanesi, yol haritası dosyalarını kendi Swift kodunuzdan okur, denetler ve planlar. Swift Package Manager ile ekleyin:

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/mobile-developer-roadmap.git", from: "2.0.0")
],
targets: [
    .target(name: "MyLearningTool", dependencies: [
        .product(name: "RoadmapKit", package: "mobile-developer-roadmap")
    ])
]
```

```swift
import Foundation
import RoadmapKit

let roadmap = try Roadmap.load(from: URL(fileURLWithPath: "roadmap"))
let plan = try roadmap.plan(to: ["flutter/architecture"], knowing: ["foundations/programming"])
for (number, topic) in plan.steps.enumerated() {
    print(number + 1, topic.id, topic.title)
}
```

Okuma sınırlıdır (dosya başına 1 MiB ve 500 konu, konu başına 32 ihtiyaç ve 16 bağlantı, dosya başına 100 bildirilen sorun). Her biçim sorunu istisna yerine dosya ve satır bilgisiyle bir `Diagnostic` olarak döner.
