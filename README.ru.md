Дорожная карта для мобильных разработчиков: сначала общие основы, затем iOS, Android, Flutter и React Native, а в конце — инженерная практика, которая помогает приложению работать и после первого релиза. В ней 124 темы. Каждая тема говорит, что изучать, какие темы освоить раньше, какой небольшой проект сделать для практики и где учиться: только первоисточники, такие как документация Apple, Android, Flutter, Dart, React Native и Expo, предложения Swift Evolution, RFC и OWASP. Содержание актуально на октябрь 2026 года: Swift 6.4 и Xcode 27, iOS 27 SDK с обязательным жизненным циклом сцен и Liquid Glass, Android 16, Flutter 3.47 с Dart 3.13 и React Native 0.88 с Expo SDK 58.

Читать дорожную карту можно прямо здесь, на GitHub, а свой путь по ней можно спланировать в терминале командой `roadmap` или пройти его в приложении RoadmapExplorer для iPhone, iPad и Mac.

## Основные возможности

- **Путь, а не список** — каждая тема называет темы, которые нужны для неё, поэтому `roadmap path` превращает цель в упорядоченный список тем для изучения, пропуская те, что вы уже знаете.
- **Только первоисточники** — 301 ссылка на официальную документацию и стандарты. Линтер отклоняет блоги, курсы и личные репозитории, а проверка ссылок каждую неделю запрашивает каждый URL.
- **Актуальные платформы** — жизненный цикл UIScene, который обязаны поддерживать приложения, собранные с iOS 27 SDK, Liquid Glass (отказ ради совместимости в сборках для iOS 27 игнорируется), безопасность Swift 6 при гонках данных, правила Android 16 для больших экранов, переход Flutter на UIScene и New Architecture в React Native, которая с версии 0.82 остаётся единственной.
- **Практика к каждой теме** — по небольшому проекту на тему, большинство из них развивают одно и то же приложение с рецептами, так что практика накапливается.
- **Один формат, с проверкой** — темы написаны на обычном Markdown с фиксированной структурой, поэтому одни и те же файлы питают GitHub, командную строку, приложение и библиотеку [RoadmapKit](#использование-библиотеки); тесты падают, если не хватает нужной темы, появляется цикл или число в документации перестаёт совпадать.

## Быстрый старт

**1. Получите дорожную карту**

```sh
git clone https://github.com/muhittincamdali/mobile-developer-roadmap.git
cd mobile-developer-roadmap
```

Нужен Swift 6.2 или новее: Xcode 26 или новее на Mac либо [Swift toolchain](https://www.swift.org/install/) на Linux. Для чтения файлов Markdown не нужно ничего.

**2. Спланируйте путь к цели**

Укажите тему, которой хотите достичь, и темы, которые вы уже знаете:

```sh
swift run roadmap path ios/swift-6-mode --known foundations/programming,ios/swift
```

При первом запуске инструмент собирается. Затем он выводит темы в том порядке, в котором их нужно изучать:

```console
$ swift run roadmap path ios/swift-6-mode --known foundations/programming,ios/swift
Path to ios/swift-6-mode: 7 topics

1. foundations/http · beginner · HTTP and web APIs
2. foundations/json · beginner · JSON and data formats
3. foundations/async · beginner · Asynchronous code and the main thread
4. ios/optionals-and-errors · beginner · Optionals and error handling
5. ios/networking · beginner · Networking with URLSession and Codable
6. ios/concurrency · intermediate · Swift concurrency
7. ios/swift-6-mode · intermediate · The Swift 6 language mode  ← goal

Skipped, already known: foundations/programming, ios/swift
```

**3. Откройте первую тему**

```sh
swift run roadmap show foundations/http
```

Команда выводит, что изучать, практический проект, темы, к которым она ведёт, и ссылки. Записывайте завершённые темы в текстовый файл по одному ID на строку и спрашивайте, с чего можно начать дальше:

```sh
printf 'foundations/programming\nios/swift\nfoundations/http\n' > my-progress.txt
swift run roadmap next --known-file my-progress.txt --track ios
```

## Commands

| Команда | Что делает |
| --- | --- |
| `roadmap tracks` | Число тем по направлениям и уровням |
| `roadmap list --track flutter --stage beginner` | Выводит ID, уровни и названия; также `--search` |
| `roadmap show react-native/new-architecture` | Одна тема с практикой, необходимыми темами, зависимыми темами и ссылками |
| `roadmap path <ID>... --known <IDs>` | Упорядоченные темы для достижения до 32 целей; также `--known-file` |
| `roadmap next --known-file my-progress.txt` | Темы, для которых вы уже знаете все необходимые; также `--track` |
| `roadmap graph --track android` | Направление в виде блок-схемы Mermaid, которую отображает GitHub |
| `roadmap lint` | Проверяет файлы дорожной карты; при любой проблеме статус завершения 1 |

Полный список команд выводит `swift run roadmap --help`. Некорректный ввод, например неизвестное направление или строка в файле прогресса, не являющаяся ID темы, не приводит к сбою, а сообщается статусом завершения 2; корректный по формату ID, которого нет в дорожной карте, — статусом 1.

## Пример: одна тема

Каждая тема — это раздел Markdown с ID, уровнем, необходимыми темами, кратким описанием, практическим проектом и источниками. Вот `ios/app-life-cycle` из [roadmap/ios.md](roadmap/ios.md):

```markdown
## ios/app-life-cycle: The app and scene life cycle

**Stage:** beginner · **Needs:** ios/swiftui

- An app has one process and one or more scenes (windows); each scene becomes active, inactive
  and enters the background on its own.
- In SwiftUI, `App` and `WindowGroup` are scene-based, and `scenePhase` reports the changes.
- UIKit apps move from `UIApplicationDelegate` window code to `UISceneDelegate`. Apple's TN3187
  says that from the release after iOS 26, an app built with the latest SDK that does not
  adopt the scene life cycle will not launch: with Xcode 27 and the iOS 27 SDK this is required.

**Practice:** Save a draft when the scene goes to the background and restore it on the next launch.

**Learn from:**

- [TN3187: Migrating to the UIKit scene-based life cycle](https://developer.apple.com/documentation/technotes/tn3187-migrating-to-the-uikit-scene-based-life-cycle)
- [Managing your app's life cycle](https://developer.apple.com/documentation/uikit/managing-your-app-s-life-cycle)
- [ScenePhase](https://developer.apple.com/documentation/swiftui/scenephase)
```

## Использование библиотеки

Библиотека `RoadmapKit` читает, проверяет и планирует файлы дорожной карты из вашего собственного кода на Swift. Добавьте её через Swift Package Manager:

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/mobile-developer-roadmap.git", from: "2.0.0")
],
targets: [
    .target(name: "MyLearningTool", dependencies: [
        .product(name: "RoadmapKit", package: "mobile-developer-roadmap")
    ])
]
```

```swift
import Foundation
import RoadmapKit

let roadmap = try Roadmap.load(from: URL(fileURLWithPath: "roadmap"))
let plan = try roadmap.plan(to: ["flutter/architecture"], knowing: ["foundations/programming"])
for (number, topic) in plan.steps.enumerated() {
    print(number + 1, topic.id, topic.title)
}
```

Чтение ограничено (1 MiB на файл, 500 тем на файл, 32 необходимые темы и 16 ссылок на тему, 100 сообщаемых проблем на файл), а каждая проблема формата возвращается как `Diagnostic` с файлом и строкой, а не как исключение.
