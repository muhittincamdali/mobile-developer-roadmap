모바일 개발자를 위한 학습 로드맵입니다. 공통 기초를 먼저 다루고, 이어서 iOS, Android, Flutter, React Native를 다룬 다음, 첫 릴리스 이후에도 앱이 계속 잘 동작하게 만드는 엔지니어링 실무로 마무리합니다. 주제는 모두 124개입니다. 각 주제는 무엇을 배워야 하는지, 먼저 배워야 할 주제는 무엇인지, 연습용 작은 프로젝트는 무엇인지, 어디에서 배울 수 있는지를 알려 줍니다. 출처는 Apple, Android, Flutter, Dart, React Native, Expo 문서, Swift Evolution 제안, RFC, OWASP 같은 1차 자료로만 한정했습니다. 내용은 2026년 10월 기준 최신입니다. Swift 6.4와 Xcode 27, scene 수명 주기가 필수이며 Liquid Glass를 갖춘 iOS 27 SDK, Android 16, Dart 3.13과 함께하는 Flutter 3.47, Expo SDK 58과 함께하는 React Native 0.88을 다룹니다.

로드맵은 GitHub에서 바로 읽을 수 있고, 터미널에서 `roadmap` 명령으로 나만의 학습 경로를 짤 수도 있으며, iPhone, iPad, Mac용 RoadmapExplorer 앱에서 따라갈 수도 있습니다.

## 주요 기능

- **목록이 아니라 경로** — 모든 주제에 선행 주제가 명시되어 있어, `roadmap path`가 목표를 이미 아는 주제는 건너뛴 학습 순서 목록으로 바꿔 줍니다.
- **1차 자료만** — 공식 문서와 표준으로 연결되는 링크 301개. linter가 블로그, 강의, 개인 저장소를 거부하며, 링크 검사는 매주 모든 URL에 요청을 보냅니다.
- **최신 플랫폼** — iOS 27 SDK로 빌드하는 앱이 반드시 적용해야 하는 UIScene 수명 주기, Liquid Glass(호환성 옵트아웃은 iOS 27 빌드에서 무시됩니다), Swift 6 데이터 레이스 안전성, Android 16 대화면 규칙, Flutter의 UIScene 마이그레이션, 그리고 0.82부터 유일한 구조가 된 React Native New Architecture.
- **모든 주제에 연습 포함** — 주제마다 작은 프로젝트가 하나씩 있고 대부분 같은 레시피 앱을 이어서 만들기 때문에 연습이 차곡차곡 쌓입니다.
- **하나의 형식, 그리고 검증** — 주제는 구조가 고정된 일반 Markdown이라서 같은 파일이 GitHub, 명령줄, 앱, [RoadmapKit](#라이브러리-사용하기) 라이브러리에 그대로 쓰입니다. 선행 주제가 빠지거나, 순환이 생기거나, 문서의 숫자가 어긋나면 테스트가 실패합니다.

## 빠른 시작

**1. 로드맵 받기**

```sh
git clone https://github.com/muhittincamdali/mobile-developer-roadmap.git
cd mobile-developer-roadmap
```

Swift 6.2 이상이 필요합니다. Mac에서는 Xcode 26 이상, Linux에서는 [Swift toolchain](https://www.swift.org/install/)을 사용하세요. Markdown 파일을 읽기만 한다면 아무것도 필요하지 않습니다.

**2. 목표까지의 경로 짜기**

도달하고 싶은 주제와 이미 아는 주제를 지정하세요.

```sh
swift run roadmap path ios/swift-6-mode --known foundations/programming,ios/swift
```

처음 실행하면 도구를 빌드합니다. 그런 다음 배울 순서대로 주제를 출력합니다.

```console
$ swift run roadmap path ios/swift-6-mode --known foundations/programming,ios/swift
Path to ios/swift-6-mode: 7 topics

1. foundations/http · beginner · HTTP and web APIs
2. foundations/json · beginner · JSON and data formats
3. foundations/async · beginner · Asynchronous code and the main thread
4. ios/optionals-and-errors · beginner · Optionals and error handling
5. ios/networking · beginner · Networking with URLSession and Codable
6. ios/concurrency · intermediate · Swift concurrency
7. ios/swift-6-mode · intermediate · The Swift 6 language mode  ← goal

Skipped, already known: foundations/programming, ios/swift
```

**3. 첫 번째 주제 열기**

```sh
swift run roadmap show foundations/http
```

배울 내용, 연습 프로젝트, 이어지는 주제, 링크를 출력합니다. 끝낸 주제는 한 줄에 ID 하나씩 텍스트 파일에 적어 두고, 다음에 시작할 수 있는 주제를 물어보세요.

```sh
printf 'foundations/programming\nios/swift\nfoundations/http\n' > my-progress.txt
swift run roadmap next --known-file my-progress.txt --track ios
```

## Commands

| 명령 | 기능 |
| --- | --- |
| `roadmap tracks` | 트랙과 단계별 주제 수 |
| `roadmap list --track flutter --stage beginner` | ID, 단계, 제목을 나열합니다. `--search`도 사용할 수 있습니다 |
| `roadmap show react-native/new-architecture` | 주제 하나를 연습, 선행 주제, 후속 주제, 링크와 함께 보여 줍니다 |
| `roadmap path <ID>... --known <IDs>` | 최대 32개 목표에 도달하기 위한 순서가 정해진 주제들. `--known-file`도 사용할 수 있습니다 |
| `roadmap next --known-file my-progress.txt` | 선행 주제를 이미 모두 아는 주제. `--track`도 사용할 수 있습니다 |
| `roadmap graph --track android` | 트랙을 GitHub이 렌더링하는 Mermaid 플로차트로 출력합니다 |
| `roadmap lint` | 로드맵 파일을 검사합니다. 문제가 있으면 종료 상태 1을 반환합니다 |

전체 목록은 `swift run roadmap --help`로 확인하세요. 알 수 없는 트랙이나, 진행 파일에서 주제 ID가 아닌 줄처럼 잘못된 입력은 충돌하지 않고 종료 상태 2로 보고됩니다. 형식은 올바르지만 로드맵에 없는 ID는 종료 상태 1로 보고됩니다.

## 예시: 주제 하나

각 주제는 ID, 단계, 선행 주제, 요약, 연습 프로젝트, 출처로 이루어진 Markdown 섹션입니다. 다음은 [roadmap/ios.md](roadmap/ios.md)에 있는 `ios/app-life-cycle`입니다.

```markdown
## ios/app-life-cycle: The app and scene life cycle

**Stage:** beginner · **Needs:** ios/swiftui

- An app has one process and one or more scenes (windows); each scene becomes active, inactive
  and enters the background on its own.
- In SwiftUI, `App` and `WindowGroup` are scene-based, and `scenePhase` reports the changes.
- UIKit apps move from `UIApplicationDelegate` window code to `UISceneDelegate`. Apple's TN3187
  says that from the release after iOS 26, an app built with the latest SDK that does not
  adopt the scene life cycle will not launch: with Xcode 27 and the iOS 27 SDK this is required.

**Practice:** Save a draft when the scene goes to the background and restore it on the next launch.

**Learn from:**

- [TN3187: Migrating to the UIKit scene-based life cycle](https://developer.apple.com/documentation/technotes/tn3187-migrating-to-the-uikit-scene-based-life-cycle)
- [Managing your app's life cycle](https://developer.apple.com/documentation/uikit/managing-your-app-s-life-cycle)
- [ScenePhase](https://developer.apple.com/documentation/swiftui/scenephase)
```

## 라이브러리 사용하기

`RoadmapKit` 라이브러리는 내 Swift 코드에서 로드맵 파일을 읽고, 검사하고, 경로를 계획합니다. Swift Package Manager로 추가하세요.

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/mobile-developer-roadmap.git", from: "2.0.0")
],
targets: [
    .target(name: "MyLearningTool", dependencies: [
        .product(name: "RoadmapKit", package: "mobile-developer-roadmap")
    ])
]
```

```swift
import Foundation
import RoadmapKit

let roadmap = try Roadmap.load(from: URL(fileURLWithPath: "roadmap"))
let plan = try roadmap.plan(to: ["flutter/architecture"], knowing: ["foundations/programming"])
for (number, topic) in plan.steps.enumerated() {
    print(number + 1, topic.id, topic.title)
}
```

읽기에는 한도가 있습니다(파일당 1 MiB와 주제 500개, 주제당 선행 주제 32개와 링크 16개, 파일당 보고되는 문제 100개). 형식 문제는 모두 예외가 아니라 파일과 줄 정보를 담은 `Diagnostic`으로 반환됩니다.
