Eine Lern-Roadmap für Mobile-Entwickler: zuerst die gemeinsamen Grundlagen, dann iOS, Android, Flutter und React Native und schließlich die Engineering-Praxis, die eine App auch nach der ersten Veröffentlichung am Laufen hält. Sie umfasst 124 Themen. Jedes Thema sagt dir, was du lernen sollst, welche Themen du zuerst lernen solltest, welches kleine Projekt zum Üben passt und wo du es lernen kannst: nur Primärquellen, etwa die Dokumentation von Apple, Android, Flutter, Dart, React Native und Expo, Swift-Evolution-Vorschläge, RFCs und OWASP. Der Inhalt ist auf dem Stand von Oktober 2026: Swift 6.4 und Xcode 27, das iOS-27-SDK mit verpflichtendem Scene-Lebenszyklus und Liquid Glass, Android 16, Flutter 3.47 mit Dart 3.13 sowie React Native 0.88 mit Expo SDK 58.

Du kannst die Roadmap hier auf GitHub lesen, mit dem Befehl `roadmap` im Terminal deinen eigenen Weg durch sie planen oder ihr in der App RoadmapExplorer für iPhone, iPad und Mac folgen.

## Highlights

- **Ein Weg, keine Liste** — jedes Thema nennt die Themen, die es voraussetzt. So macht `roadmap path` aus einem Ziel die geordnete Liste der zu lernenden Themen und überspringt dabei die, die du schon kennst.
- **Nur Primärquellen** — 301 Links auf offizielle Dokumentation und Standards. Ein Linter lehnt Blogs, Kurse und private Repositorys ab, und die Linkprüfung ruft jede URL einmal pro Woche ab.
- **Aktuelle Plattformen** — der UIScene-Lebenszyklus, den Apps übernehmen müssen, die mit dem iOS-27-SDK gebaut werden, Liquid Glass (das Opt-out für die Kompatibilität wird bei iOS-27-Builds ignoriert), die Data-Race-Sicherheit von Swift 6, die Android-16-Regeln für große Bildschirme, die UIScene-Migration von Flutter und die New Architecture von React Native, die seit 0.82 die einzige ist.
- **Übung zu jedem Thema** — ein kleines Projekt pro Thema, die meisten bauen auf derselben Rezept-App auf, sodass sich das Geübte aufeinander aufbaut.
- **Ein Format, geprüft** — die Themen sind schlichtes Markdown mit fester Struktur, daher speisen dieselben Dateien GitHub, die Kommandozeile, die App und die Bibliothek [RoadmapKit](#die-bibliothek-verwenden); Tests schlagen fehl, wenn eine Voraussetzung fehlt, eine Schleife entsteht oder eine Zahl in der Dokumentation nicht mehr stimmt.

## Schnellstart

**1. Die Roadmap holen**

```sh
git clone https://github.com/muhittincamdali/mobile-developer-roadmap.git
cd mobile-developer-roadmap
```

Du brauchst Swift 6.2 oder neuer: Xcode 26 oder neuer auf einem Mac oder eine [Swift-Toolchain](https://www.swift.org/install/) unter Linux. Zum Lesen der Markdown-Dateien brauchst du gar nichts.

**2. Einen Weg zu einem Ziel planen**

Nenne das Thema, das du erreichen willst, und die Themen, die du schon kennst:

```sh
swift run roadmap path ios/swift-6-mode --known foundations/programming,ios/swift
```

Beim ersten Start wird das Tool gebaut. Danach gibt es die Themen in der Reihenfolge aus, in der du sie lernen solltest:

```console
$ swift run roadmap path ios/swift-6-mode --known foundations/programming,ios/swift
Path to ios/swift-6-mode: 7 topics

1. foundations/http · beginner · HTTP and web APIs
2. foundations/json · beginner · JSON and data formats
3. foundations/async · beginner · Asynchronous code and the main thread
4. ios/optionals-and-errors · beginner · Optionals and error handling
5. ios/networking · beginner · Networking with URLSession and Codable
6. ios/concurrency · intermediate · Swift concurrency
7. ios/swift-6-mode · intermediate · The Swift 6 language mode  ← goal

Skipped, already known: foundations/programming, ios/swift
```

**3. Das erste Thema öffnen**

```sh
swift run roadmap show foundations/http
```

Das gibt aus, was du lernen sollst, das Übungsprojekt, die Themen, zu denen es weiterführt, und die Links. Halte die Themen, die du abgeschlossen hast, in einer Textdatei fest, eine ID pro Zeile, und frage, womit du als Nächstes beginnen kannst:

```sh
printf 'foundations/programming\nios/swift\nfoundations/http\n' > my-progress.txt
swift run roadmap next --known-file my-progress.txt --track ios
```

## Commands

| Befehl | Was er tut |
| --- | --- |
| `roadmap tracks` | Themen pro Track und Stufe |
| `roadmap list --track flutter --stage beginner` | Listet IDs, Stufen und Titel auf; auch mit `--search` |
| `roadmap show react-native/new-architecture` | Ein Thema mit Übung, Voraussetzungen, abhängigen Themen und Links |
| `roadmap path <ID>... --known <IDs>` | Die geordneten Themen, um bis zu 32 Ziele zu erreichen; auch mit `--known-file` |
| `roadmap next --known-file my-progress.txt` | Themen, deren Voraussetzungen du schon kennst; auch mit `--track` |
| `roadmap graph --track android` | Ein Track als Mermaid-Flussdiagramm, das GitHub darstellt |
| `roadmap lint` | Prüft die Roadmap-Dateien; Exit-Status 1 bei jedem Problem |

Mit `swift run roadmap --help` siehst du die vollständige Liste. Ungültige Eingaben, etwa ein unbekannter Track oder eine Zeile in der Fortschrittsdatei, die keine Themen-ID ist, werden mit Exit-Status 2 gemeldet, statt abzustürzen; eine wohlgeformte ID, die nicht in der Roadmap vorkommt, mit Exit-Status 1.

## Beispiel: ein Thema

Jedes Thema ist ein Markdown-Abschnitt mit einer ID, einer Stufe, den Voraussetzungen, einer Zusammenfassung, einem Übungsprojekt und den Quellen. Das ist `ios/app-life-cycle` in [roadmap/ios.md](roadmap/ios.md):

```markdown
## ios/app-life-cycle: The app and scene life cycle

**Stage:** beginner · **Needs:** ios/swiftui

- An app has one process and one or more scenes (windows); each scene becomes active, inactive
  and enters the background on its own.
- In SwiftUI, `App` and `WindowGroup` are scene-based, and `scenePhase` reports the changes.
- UIKit apps move from `UIApplicationDelegate` window code to `UISceneDelegate`. Apple's TN3187
  says that from the release after iOS 26, an app built with the latest SDK that does not
  adopt the scene life cycle will not launch: with Xcode 27 and the iOS 27 SDK this is required.

**Practice:** Save a draft when the scene goes to the background and restore it on the next launch.

**Learn from:**

- [TN3187: Migrating to the UIKit scene-based life cycle](https://developer.apple.com/documentation/technotes/tn3187-migrating-to-the-uikit-scene-based-life-cycle)
- [Managing your app's life cycle](https://developer.apple.com/documentation/uikit/managing-your-app-s-life-cycle)
- [ScenePhase](https://developer.apple.com/documentation/swiftui/scenephase)
```

## Die Bibliothek verwenden

Die Bibliothek `RoadmapKit` liest, prüft und plant die Roadmap-Dateien aus deinem eigenen Swift-Code. Füge sie mit dem Swift Package Manager hinzu:

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/mobile-developer-roadmap.git", from: "2.0.0")
],
targets: [
    .target(name: "MyLearningTool", dependencies: [
        .product(name: "RoadmapKit", package: "mobile-developer-roadmap")
    ])
]
```

```swift
import Foundation
import RoadmapKit

let roadmap = try Roadmap.load(from: URL(fileURLWithPath: "roadmap"))
let plan = try roadmap.plan(to: ["flutter/architecture"], knowing: ["foundations/programming"])
for (number, topic) in plan.steps.enumerated() {
    print(number + 1, topic.id, topic.title)
}
```

Das Einlesen ist begrenzt (1 MiB pro Datei, 500 Themen pro Datei, 32 Voraussetzungen und 16 Links pro Thema, 100 gemeldete Probleme pro Datei), und jedes Formatproblem kommt als `Diagnostic` mit Datei und Zeile zurück statt als Exception.
